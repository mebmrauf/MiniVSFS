MiniVSFS is a tiny file system for learning how files are stored on a disk.

Or drop your own .img file here. It stays on this computer.

To make your own image, run these commands, then open out2.img here:

git clone https://github.com/mebmrauf/MiniVSFS.git
cd MiniVSFS
gcc -O2 -std=c17 mkfs_builder.c -o mkfs_builder
gcc -O2 -std=c17 mkfs_adder.c -o mkfs_adder
./mkfs_builder --image out.img --size-kib 180 --inodes 128
./mkfs_adder --input out.img --output out2.img --file file_8.txt
